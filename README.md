# Rubiks-Cube-Solver
Open source Rubik's Cube solver in a self contained, single html file. 


Open `index.html` in a browser (no build, no dependencies). Hold the cube with white on top and green in front, enter the colours face by face (front, right, back, left, top, bottom), press **Solve it!**, then click **Next ▶** to step through the animated solution.
